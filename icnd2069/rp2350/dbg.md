# 一个30m的效果还行的case
r信号不能驱动b
rb信号可以驱动b
gray范围选0-512 这样b就可以看清了
杜邦线连接时 噪声可能太大 配置大概率失效 要在低速下写入配置
排查下来是面板的lines实际是 10(3+3+4)x16=160 也就是扫描还是64行 
chains 从1->2或从2->1 噪声就没了 很奇怪 (30m的时候噪声影响 导致特定条件下数据才能准确写入)
25m下 这些问题就没了 还是物理硬件的限制
gclk太慢的话 outx会超过一行的宽度 图像也会很多噪声

hdl的branch:
目前一个pico2意外用了5v io 在12ma的驱动电流下直接飞线驱动可以30m无噪声
现在同样的led面板和pico2 使用devboard可以点亮 但是使用cpld板仅飞线时却有噪声 怀疑和pin布局有关 cpld板仅用5v的pico板可以无噪声
cpld板子使用多个3.3v pico 都有巨大噪声 哪怕只有12.5mhz 看来cpld板的clk走线还是太长 噪声太大

现在显示的图像 主要的斜线可以看清 但是有很多噪声 这些噪声都是斜线随机平移产生的 在5v的pico下没有噪声 3.3v的pico下是有的 不管dclk多慢都是这样

## VCC 重插线索应如何解释

编程指南 V4.2 p.5 对 SOFT_RST 的定义是 **“Reset other functions except registers”**。软件复位不清寄存器，不能用它模拟断电重上电。[6]

当前固件只在 `main()` 启动时调用一次 `encode_init()`，循环中只发送显示帧。因此：

1. 若 ICND2069 已有电，再复位 RP2350，芯片会收到 SOFT_RST、DIS_OP 和整套配置写入。
2. 若 RP2350 一直运行，仅给 ICND2069 重新上电，芯片可能只收到循环中的 VSYNC、EN_OP、灰度和 ROW，没有重新收到配置表。
3. 指南 p.10 说明上电后输出默认关闭，收到帧数据及 EN_OP 才打开；当前循环持续发送 EN_OP，故重上电后重新出现活动与这一机制相容。

以上解释是**待验证的状态差异假设**，不是已经读回寄存器确认的根因。指南中的“默认配置表”也不能自动等同于当前芯片实测上电复位值。

优先候选包括：配置值与具体 ICND2069 版本不匹配、DIS_OP/EN_OP 相关内部状态、PLL 设置或锁定过程，以及供电/信号上电顺序。没有 VCC 测量，不能确认拔掉电源后是否完全掉电；输入信号可能影响断电状态，需要测量才能判断。

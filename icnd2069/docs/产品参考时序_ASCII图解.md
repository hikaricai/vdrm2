# 产品参考抓包时序：ASCII 图解

来源：[261024_250m_2s.dsl](../../dsview/icnd2069/261024_250m_2s.dsl)。参考产品按 **8 颗级联、40 行、64 遍扫描**解析。本文画的是旧产品抓包，并标出当前 [`timing` 配置](../rp2350/config.json)对应的测量位置。

**先发 VSYNC，再开启输出和 ROW 扫描；扫描期间发送配置、写入灰度；最后等待下一次 VSYNC。**

所有数字均以 **DCLK 上升沿个数**为单位，`K=0` 是本帧 VSYNC 的 **LE 拉高沿**，不是 VSYNC 结束。图横向不按比例；`...` 表示省略区间。DCLK 全程持续运行。

## 1. 整帧：扫描与传灰度同时进行

下面使用抓包中第一个完整帧，其下一次 VSYNC 在 `K=208079`。

```text
K        0      28          732      860          87803       207649     208079
         |       |           |        |              |            |          |
VSYNC    ^-------+-----------+--------+--------------+------------+----------^
                 |           |        |              |            |
ROW              +===============================================+
                 start       |        |              |      last ROW falls
                 K=28        |        |              |
GRAY                         +=======================+
                             first    first          last
                             bit      latch ends     latch ends
                             K=732    K=860          K=87803
                                                                  <---------->
                                                                  frame_tail
                                                                     430
```

`ROW` 这一条长条表示连续扫描阶段，**不是 ROW 始终为高**；实际是 2560 个脉冲。首次灰度锁存结束前已经启动了 11 个 ROW，全部灰度锁存结束前已启动了 1084 个 ROW。

## 2. 帧头：三个 start 参数从哪里量

```text
VSYNC LE rises: K=0
  |
  +-- en_start   =  15 --> EN_OP LE rises       K=15
  |
  +-- row_start  =  28 --> first ROW rises      K=28
  |
  +-- gray_start = 732 --> first gray bit       K=732

LE command pulses:

       +-- VSYNC --+          +---- EN_OP ----+       +---- PRE_ACT ----+
LE  ___|          |__________|               |_______|                 |___...
K      0          3          15              26      29                43
       <--- 3 --->           <----- 11 ----->        <------ 14 ------->

First ROW pulse (independent of LE):

                             +--------- ROW ---------+
ROW _________________________|                       |___________________...
K                            28                      40
                             <--------- 12 ---------->
```

两段波形各自按下方 K 标注定位，不按字符列上下对齐。EN 在 `K=26` 结束，**再过 2 个 DCLK** 启动 ROW；到 `K=29` 才开始 PRE_ACT，因此 ROW 与后续配置重叠。

参考产品随后每帧写五次配置。下图方括号表示 **LE 高电平命令区间**，不是全部配置数据的传输窗口：

```text
PRE_ACT       WR_CFG        WR_CFG        WR_CFG        WR_CFG        WR_CFG
[29,43) --> [175,180) --> [311,316) --> [447,452) --> [583,588) --> [719,724)
             00=AA         01=AA        rotating       00=55         01=55
             unlock        unlock       one item       lock          lock

K=724                 K=732
  |------- 8 DCLK -------|
  last WR_CFG ends       first gray block begins
```

`gray_start=732` 由首次锁存前的 **8×16=128 位**有效窗口回推。首块数据为全零，SIN 没有唯一的“开始发送”跳变；该值不能当作控制器内部状态切换的实测时刻。首位在第 **733 个**上升沿采入，此前已经经过 732 个上升沿。

## 3. 灰度：字间隔和跨行间隔

这里的一个“灰度块”包含 **同一个 OUT 的 8 个级联字**，RGB 三条链并行发送。每块 128 个 DCLK；LE 仅在最后一个 DCLK 为高，随后下降完成 DATA_LATCH。

```text
First gray block: row 0, OUT15

K       732                                          859      860
        |                                             |        |
SIN     [------------ 8 chips x 16 bits = 128 DCLK ------------]
                                                      +--------+
LE      ______________________________________________|        |____
        ^                                             ^        ^
        gray_start                                    LE rises latch ends

Two adjacent blocks in the SAME data row:

K       732                     860       868                     996
        |                        |         |                        |
GRAY    [ OUT15: 128 DCLK         ]-- 8 ---[ OUT14: 128 DCLK         ]
                                 |         |                        |
                                 <-------- latch interval = 136 --->
                                 <--- 8 --->
                                 gray_word_gap

Across TWO data rows:

K       2772                    2900      2909                    3037
        |                        |         |                        |
GRAY    [ row 0, OUT0: 128 DCLK   ]-- 9 ---[ row 1, OUT15: 128 DCLK  ]
                                 |         |                        |
                                 <-------- latch interval = 137 --->

                                 9 = gray_word_gap + gray_row_gap
                                   =       8       +      1
```

因此 `gray_word_gap=8` 加在**两个灰度块之间**，不是每颗芯片的 16 位字之间。跨行在此基础上再加 `gray_row_gap=1`。

每帧共 `40×16=640` 次锁存，顺序为每行 OUT15→OUT0：

```text
row 0: OUT15, OUT14, ... , OUT0  -> row 1: OUT15, ... -> row 39: ... , OUT0
       latch ends K=860   K=2900          K=3037                       K=87803

j = 0..639
gray block starts at K = 732 + 136*j + floor(j/16)
latch ends at K       = 860 + 136*j + floor(j/16)
```

灰度“写入行”与 ROW 此刻正在扫描的行是两件事，不能由此图推断刚写入的字立即显示。

## 4. ROW：脉冲宽度不等于换行周期

```text
          first pulse                         second pulse
          +------------+                      +----+                     +----+
ROW ______|            |______________________|    |_____________________|    |__
K         28           40                     109  113                   190  194
          <--- 12 -----><-------- 69 ---------><--4-><-------- 77 -------->
          <---------- period = 81 -----------><------ period = 81 ------>
                      row_period                        row_period
```

首脉冲高 **12**，其余高 **4**。`row_period` 量的是**相邻 ROW 上升沿的距离**。

参考包的周期并非全部为 81；以下都是实际抓到的上升沿：

```text
K       838 ----81----> 919 ----80----> 999 ----82----> 1081
        ...
K      3104 ----81---> 3185 ----83---> 3268
```

每完整帧有 2560 个 ROW，2559 个相邻间隔中：80 出现 141 次、81 出现 1983 次、82 出现 391 次、83 出现 44 次。**配置中的 `row_period=81` 取主值；它不表示原包为固定 81 周期。**

## 5. 帧尾：frame_tail 从最后 ROW 下降沿量起

```text
K     207645 207649                                    208079 208082
         |      |                                         |      |
         +------+                                         |      |
ROW _____|      |_____________________________________________________
                                                          +------+
LE  ______________________________________________________|      |____
         <--4-->|                                         |<-3-->|
                <----------- frame_tail = 430 ------------>
                last ROW falls                            next VSYNC rises

208079 - 207649 = 430
```

430 是参考包**第一个完整帧**的测量值。全包末 ROW 下降沿到下一次 VSYNC 为 **380～465 DCLK**；相邻 VSYNC 为 **208029～208114 DCLK**。最后 ROW 下降沿不代表 LED 已停止发光。

## 6. 七个参数与当前代码的对应关系

| 参数 | 已填值 | 参考依据 |
|---|---:|---|
| `en_start` | 15 | VSYNC LE↑ → EN_OP LE↑，固定实测 |
| `gray_start` | 732 | VSYNC LE↑ → 首个灰度有效窗口，按 128 位回推 |
| `row_start` | 28 | VSYNC LE↑ → 首个 ROW↑，固定实测 |
| `gray_word_gap` | 8 | 同一数据行内两块之间的空闲 DCLK |
| `gray_row_gap` | 1 | 跨数据行比同行间隔多出的 DCLK |
| `row_period` | 81 | 原包 80～83 中的主值 |
| `frame_tail` | 430 | 原包首个完整帧的尾间隔，全部帧范围 380～465 |

当前固件中，`timing` 控制**普通显示帧**。`repeat_latch` 开启时，字/行间隔沿用重复锁存算法；`keep_scan_time=true` 时，ROW 周期由灰度窗口均分决定。`frame_tail` 是最小间隔，数据或扫描尚未完成时会延后。

当前两颗链与参考八颗链的长度不同：完整写入首次锁存为 `732+32=764`；当前正向斜线、重复锁存间隔 1 时，首次零字锁存为 `732+1+1=734`。**图中的 860 属于参考八颗完整写入。** 参考产品的每帧五次配置写入也不等于当前固件的启动/周期完整配置流程。

# ICND2069 CPLD：三组 RGB × 六路选择

移植自 `../mbi5264/`，目标器件 **LCMXO2-1200HC-4TG100C**。
接线依据本目录 `SCH_Schematic5_2026-11-21.pdf` 的 U1。
67 个业务 IO：CLK、三组 SEL/R/G/B，以及 54 个 RGB 输出。没有 SEL_LAT。

## 八时钟选址协议

SEL 在 CLK 上升沿采样，每组独立发送以下八位，高位先发：

```text
CLK 上升沿序号    1   2   3   4   5   6   7   8
SEL              a2  a1  a0  0   1   1   1   1
                 └─地址─┘  隔离  └─锁存标记─┘
```

第 8 个上升沿锁存前三位地址。第四位必须为 0，将地址末尾的 1
与锁存标记隔开，因此地址 `011`、`111` 均不会提前触发。
帧可以连续发送，不需要额外 CLK、复位或帧间隔。
三组 SEL 可以并行选址，全部组总共仍只需 8 个 CLK。

| 地址 | 帧字节 | 选择的原理图后缀 |
| --- | --- | --- |
| 0 / 000 | 0x0F / 00001111 | 1 |
| 1 / 001 | 0x2F / 00101111 | 3 |
| 2 / 010 | 0x4F / 01001111 | 5 |
| 3 / 011 | 0x6F / 01101111 | 7 |
| 4 / 100 | 0x8F / 10001111 | 9 |
| 5 / 101 | 0xAF / 10101111 | 11 |
| 6 / 110 | 0xCF / 11001111 | 本组广播 |
| 7 / 111 | 0xEF / 11101111 | 本组广播 |

例如第 1 组选地址 3，驱动的是 R17/G17/B17；
第 3 组选地址 5，驱动的是 R311/G311/B311。
总线下标 0～5 对应后缀 1、3、5、7、9、11。

MCU 端的帧字节为 `(address << 5) | 0x0F`，address 范围 0～7。
每个 CLK 上升沿发送一位，必须提前满足 SEL 的建立时间，
并在上升沿后满足保持时间。这里的 8 CLK 指完整时钟周期，
不能直接等同于旧 MCU PIO 的 8 个双沿 color 字。

普通 RGB 传输期间将 SEL 固定为 0，地址保持不变。
完整标记后继续保持 SEL 为 1 也不会重复锁存，
但从 0 转为连续四个 1 会形成新的标记，业务期间应使用低电平空闲。
上电地址为 0；未接收满八次上升沿不会接受标记。
此协议不带校验，丢时钟或随意切换 SEL 可能形成有效标记。

## RGB 路由时序

沿用原工程双沿采样方式：每个 CLK 上升沿和下降沿采样 RGB，
同组所有输出使用同一个选择地址，并在两个边沿之间保持。
六路均采用寄存器保持，没有旧工程中的组合直通例外。
上电输出寄存器为 0。

地址在第 8 个上升沿更新，该上升沿的 RGB 样本仍使用旧地址；
同一 CLK 的下降沿开始使用新地址。发送选址帧时保持 RGB 为 0，
第 8 个下降沿之后再设置新地址对应的 RGB 数据。
选址过程仍有下游时钟和 RGB 样本，MCU 须在合适的数据边界安排选址，
并考虑这些时钟对 ICND2069 串行数据长度的影响。

双沿保持沿用两个相反边沿的寄存器与 XOR 交叉反馈，
不是器件原生 DDR。内部时序检查及零延迟仿真
不能替代外部接收器的建立保持检查或上板毛刺验证。

## 构建、仿真和烧录

沿用原工程 Yosys → nextpnr-machxo2 → ecppack 流程和本地工具链目录。

```sh
bash lcmxo2/project/icnd2069/sim.sh
bash lcmxo2/project/icnd2069/sim-synth.sh
bash lcmxo2/project/icnd2069/build.sh
```

码流：`build-open/led.bit`。构建和仿真不访问硬件。
仅需综合时执行 `synth.sh`。

用户需要烧录时执行：

```sh
bash lcmxo2/project/icnd2069/flash.sh
```

烧录脚本先构建，检测 DirtyJTAG 上的 IDCODE 必须为
1200HC 的 `0x012ba043`，再写入 Flash 并验证。
沿用原烧录流程的 Feature Row 参数 `0x620`，保持 JTAG 可用。
本次未执行烧录。

## 引脚

全部约束见 `board.lpf`，采用 LVCMOS33，VCCIO 应为 3.3 V。
已逐脚核对本地 MachXO2-1200 pinout CSV 的 TQFP100 列：
67 个唯一 IO，未占用独立 JTAG 的 90/91/94/95 脚。

| 组 | 输入 R/G/B 脚号 | SEL 脚号 |
| --- | --- | --- |
| 1 | 85 / 86 / 87 | 88 |
| 2 | 96 / 97 / 98 | 99 |
| 3 | 27 / 28 / 29 | 30 |

CLK 为 35 脚，属于 PCLKC2_0。
1200 数据库自动布局的 `X12/Y6/DCC0` 可以成功布线，
无需沿用旧 2000 工程的固定 DCCA BEL。

## 2026-11-21 验证结果

- RTL 与综合后网表分别通过 22,618 次输出检查。
- 覆盖全部八个地址、512 种 RGB 输入组合、连续帧、地址末尾连 1、
  三组独立选址、长串 1、错误标记、上电不完整标记、
  双沿采样、边沿间保持和暂停时钟。
- 1200HC-4TG100C 完成综合、布局布线及压缩码流生成。
- 使用 147/1280 个 FF、236/1280 个组合单元、1/8 个 DCCA。
- 布线后内部最高频率报告为 73.17 MHz，16.25 MHz 目标通过；
  该报告不代表外部 IO 能保证以 73.17 MHz 工作。
- 未烧录，尚无新板实际波形验证。

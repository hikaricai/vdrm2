# ICND2069 抓包寄存器汇总

更新：2026-10-24。本文汇总三次实际抓包中的寄存器写入，供复现当前板卡配置及后续对比使用。指南中的默认值和完整字段说明另见 [ICND2069-寄存器配置整理.md](ICND2069-寄存器配置整理.md)。

**50 MHz 开机包与最新 250 MHz 包覆盖同一组 47 个地址，45 个常规配置地址的 RGB 值全部一致。100 MHz 短包只覆盖其中 4 个地址，共同出现的写入值也一致。两次长包都显示控制器每帧轮转重写一项，47 帧循环一次。**

共同通道映射：CLK=CH0、LAT=CH1、R=CH2、G=CH5、B=CH6。每路按 8 颗级联解析；三包中每次配置写入的同一颜色链内，8 个字全部一致。

本文的“值”均指 **SIN/RGB 数据线上观察到的写入值**。三包均未出现 RD_CFG，没有 SDO 读回结果，不能据此证明芯片实际接受了每次写入，也不能把这些值称为芯片复位默认值。47 个地址是当前指南整理及抓包覆盖集合，不代表芯片不存在其他地址。

## 3. 00 / 01：配置访问控制

它们不适合并入上表作为单个固定配置值。以下 RGB 相同，次数按命令统计：

| 地址=值 | A 次数 | B 次数 | C 次数 | 作用 / 出现场景 |
|---|---:|---:|---:|---|
| 00=AA | 2 | 529 | 129 | 每帧解锁第一步 |
| 01=AA | 2 | 529 | 129 | 每帧解锁第二步 |
| 00=55 | 2 | 540 | 131 | 每帧锁回，另加轮转表中的同值项 |
| 01=55 | 2 | 540 | 131 | 每帧锁回，另加轮转表中的同值项 |
| 00=00 | 未见 | 1 | 未见 | B 首帧轮转项，时间 1.393066660 s |

因此，B 与 C 唯一额外观测到的地址/值组合差异是 B 启动时的 `00=00`，没有发现两包之间的常规显示配置值差异。

## 4. 控制器如何持续重发配置

每帧顺序：

```text
VSYNC → EN_OP → PRE_ACT
→ 00=AA → 01=AA
→ 轮转表中的一项
→ 00=55 → 01=55
→ 灰度数据
```

稳定轮转表按以下顺序循环，**共 47 项，每帧一项**：

```text
00=55 → 01=55
→ 02 → 03 → …… → 22
→ 70 → 71 → 72 → 73 → 74
→ F0 → F1 → F2 → F3 → F4 → F5
→ 23 → 回到 00=55
```

在约 60 Hz 帧率下，一轮约 0.7833 秒。A 只抓到连续的 `72 → 73`；B 从第 13 帧开始完整重复 11 轮；C 从 `0A` 开始观察到 2 轮加 35 项。两次长包共同表明，短包中的 `72/73` 是更长配置轮转表的一段，并非只有这两个地址交替重写。

轮转项为 `00/01` 时，仍保留固定的解锁和锁回序列，因此会重复发送 `0055/0155`。这是抓到的控制器行为，不能据此认为每项配置必须单独解锁：指南允许一次 PRE_ACT、解锁后连续写多项，再统一锁回。

## 5. 这组配置对应什么显示参数

| 项目 | 结果 | 依据及边界 |
|---|---|---|
| 扫描数 | 40 | `(02 & 3F) + 1 = 40`；完整灰度块也为 40×16 次锁存 |
| 显示组数 | 64 | `(03 & 7F) + 1 = 64` |
| 输入帧率 | 约 60 Hz | 三包 VSYNC；B 启动前两次间隔例外 |
| 灰度相关 K | 32 | 07=08=20 |
| 指南公式刷新率 | 约 3840 Hz | 64×60；是配置推算，未直接测输出刷新 |
| 指南公式灰度容量 | 8192 | 64×32×4；串行数据字仍为 16 位 |
| 内部 GCLK | 尚不能确定 | 04=04、05=0A、06=01，但指南 N 编码映射不清楚 |
| 实际输出电流 | 尚不能确定 | 已有 1C 参数，仍需硬件电阻及可靠电流公式 |

R/G/B 实测配置有差别的地址共 **8 个**：
`0C、0E、18、19、1C、1E、1F、23`。复现配置时不能把 R 的整张表直接复制给 G/B。

相对指南默认值表，至少一路不同的地址为 **12 个**：
`04、05、06、0C、0E、10、19、1C、1D、1E、20、23`。`02` 是按扫描数设置，不计入这 12 个固定默认值差异。

## 6. 灰度变化与配置变化分别看

B 开机包所有灰度为零，C 最新包和 A 短包则是每行 OUT15 为零、其余已传通道为 `02B8`。B/C 的 45 个常规配置地址全部相同，所以这两包所观察到的变化发生在输入灰度数据中。

这并不能证明两次采集之间从未临时改过寄存器；也不能用 C 补齐 A 未抓到的寄存器状态。当前证据支持的是：**在各自采集窗口内，B/C 持续重发相同的常规配置值；A 的共同地址值与它们一致。**

## 7. 核对依据

地址和值来自三包的 WR_CFG 串行字，高 8 位为地址、低 8 位为值。每次写入均核对 RGB 三路和每路 8 字；对 C 的 645 条 WR_CFG 另外从原始 DSL 位流重新读取末尾 128 位，并核对 LAT 高期间的 5 个 CLK 上升沿，与解码输出一致。

A、C 无解码告警；B 唯一告警是采集开始时 LAT 已经为高，缺失脉冲起点，与后面的寄存器写入无关。功能解释以本目录的 [编程指南 V4.2](ICND2055-ICND2065-ICND2059-ICND2069-Programming-Guide-EN-2019-V4.2-Olympian.pdf) 和 [寄存器配置整理](ICND2069-寄存器配置整理.md) 为依据；指南未说明的字段保持未知。

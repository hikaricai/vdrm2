# 250 MHz / 2 秒抓包：寄存器提取汇总

来源：`261024_250m_2s.dsl`，采样率 250 MHz，536,870,912 点，实际时长 **2.147483648 秒**。通道沿用 CLK=0、LAT=1、R=2、G=5、B=6，每路按 8 颗级联解析。时间以抓包起点为零，写入时刻取 LAT 下降沿。

**本包包含全部 47 个已整理地址。45 个常规配置地址的 RGB 写入值均与 50 MHz 开机包一致，包内未发生配置值变化。**

## 1. 提取结果

| 项目 | 结果 |
|---|---|
| WR_CFG | 645 条 |
| VSYNC / EN_OP / PRE_ACT | 各 129 条 |
| 每帧配置访问 | 固定 5 条 WR_CFG：两条解锁、一条轮转项、两条锁回 |
| 轮转周期 | 47 帧，约 0.783335 秒 |
| 每条配置的级联字 | RGB 各 8 个 16 位字；同一颜色链中全部相同 |
| RD_CFG | 0，没有寄存器读回值 |
| 未知命令 / 不完整 LAT 脉冲 / 解码告警 | 均为 0 |

计数单位为 **WR_CFG 命令次数**，不是 RGB 三路、每路 8 颗相乘后的字数。

`0x00/0x01` 单列为配置访问控制：

| 地址 | RGB 写入值 | 次数 | 说明 |
|---|---|---:|---|
| 00 | AA / AA / AA | 129 | 每帧解锁第一步 |
| 01 | AA / AA / AA | 129 | 每帧解锁第二步 |
| 00 | 55 / 55 / 55 | 131 | 每帧锁回 129 次，加轮转项 2 次 |
| 01 | 55 / 55 / 55 | 131 | 每帧锁回 129 次，加轮转项 2 次 |

本包没有出现开机包首帧的 `00=00`。

## 3. 实际发送顺序

每帧都是：

```text
VSYNC → EN_OP → PRE_ACT
→ WR_CFG(00, AA) → WR_CFG(01, AA)
→ WR_CFG(本帧轮转地址, 对应 RGB 值)
→ WR_CFG(00, 55) → WR_CFG(01, 55)
→ 640 次 DATA_LATCH → 等待下一帧
```

本包从轮转表的 `0x0A` 位置开始：

| 帧号 | 中间轮转项 |
|---|---|
| 1～25 | 0A、0B、……、22 |
| 26～30 | 70、71、72、73、74 |
| 31～36 | F0、F1、F2、F3、F4、F5 |
| 37 | 23 |
| 38～39 | 00=55、01=55 |
| 40～47 | 02、03、……、09 |
| 48～94 | 重复第 1～47 帧 |
| 95～129 | 再重复第 1～35 帧，结束于 F4 |

第一次 VSYNC 在 0.005596200 s，最后一次在 2.138933540 s。128 个帧间隔平均为 **16.666698 ms**，约 60 Hz；最小/最大为 16.665132 / 16.668260 ms。

## 4. 与前两次抓包对照

- **50 MHz 开机包**：45 个常规配置地址逐一对比，R/G/B 全部一致。不同之处是开机包曾出现一次 `00=00`；正常轮转和访问控制一致。
- **100 MHz / 20 ms 短包**：只覆盖 `00、01、72、73`，共同观测到的写入值一致。短包未出现的地址不能用零值补齐，也不能从本包反推它当时的寄存器状态。
- **灰度数据**：本包共 82,560 次锁存，129 个灰度块均为 640 次。每行 OUT15 为 `0000`，OUT14～OUT0 为 `02B8`，RGB 和 8 个级联字都相同，与旧短包的规律一致；开机包全为零。最后一个灰度块完整，但其后的下一次 VSYNC 在抓包外。

因此，本次与开机包之间没有观察到常规配置值变化，输入灰度数据已经发生变化。

## 5. 提取和验证范围

配置地址取串行 16 位字的高 8 位，值取低 8 位。已对本包 **645 条 WR_CFG** 逐条从 DSL 原始位流独立回取最后 128 个 CLK 上升沿上的 RGB 位，并检查 LAT 高期间均覆盖 5 个上升沿；与解码结果一致。也逐条核对了所有灰度锁存的 OUT15/其余通道数据规律。

这里汇总的是控制器发送的写入值；未采集 SDO 读回确认。`F1/F2` 写零的事实，不代表指南已确认它们可作为普通配置寄存器写入。

# P0.93 LED 板芯片资料：ICND2069AP 与 RT5990

本目录已提供 Rust DSL 解码程序，运行方法、字段说明及当前抓包结果见 [ICND2069 解码器说明](DECODER.md)。

编程指南中的地址、位定义、默认值、公式与原文疑点见 [ICND2069 寄存器配置整理](ICND2069-寄存器配置整理.md)。

ICND2019 共阴行驱动的原厂参数、引脚资料状态及与 RT5990 的区别见 [ICND2019 芯片资料](ICND2019-芯片资料.md)，原厂[产品选型手册](Chipone-2025-产品选型手册-CN.pdf)已保存到本目录。

研究日期：2026-10-23。对象：闲鱼购买的 P0.93 LED 板，已知板上主要芯片丝印为 `ICND2069AP` 和 `RT5990`。本文区分厂商已确认信息、由系统结构得出的推断，以及仍需实物测量的未知项。

## 结论

这是一套面向小间距共阴 LED 扫描屏的驱动组合：

- `ICND2069AP` 是集创北方（Chipone）的 16 通道 PWM 恒流源驱动芯片，负责 RGB 列的恒流、灰度 PWM 和帧数据存储；支持最高 1/64 扫描。[cite:1][cite:2]
- `RT5990` 是锐发科技（Raffar）的 16 通道 NMOS 行管控制芯片，负责选择共阴 LED 的扫描行，并集成串行译码、鬼影抑制和坏灯串亮抑制。[cite:5]
- 高概率电流路径是：电源正端 -> `ICND2069AP OUT0...OUT15` -> LED 阳极；LED 公共阴极 -> `RT5990` 的 NMOS 输出 -> 地。这个连接关系符合两颗芯片的官方功能定义，但最终仍应通过 PCB 走线或二极管档测量确认。
- 实物接口存在 `Vrg`、`Vb` 电源标识，说明 LED 侧至少分成两组供电轨。这与共阴节能屏按颜色正向压降配置阳极电源的做法一致，但两组电源分别连接哪些颜色仍需测量确认。
- `AP` 是封装后缀，不是芯片修订版：`ICND2069AP` 对应 SSOP24、0.635 mm 引脚间距；另一个 `AN-01` 后缀才是 QFN24 4 mm × 4 mm 封装。[cite:2]
- ICND2069 不是传统、无状态的 16 通道移位寄存器。它带帧缓存 SRAM、配置寄存器和基于 `LE` 高电平期间 DCLK 上升沿个数的命令解析器。仅按普通 HUB75 的 `CLK/LAT/OE` 时序驱动，不能正确工作。[cite:1][cite:3]

## 芯片分工

| 芯片 | 厂商 | 类型 | 在板上的作用 | 公开资料状态 |
|---|---|---|---|---|
| ICND2069AP | 北京集创北方 | 16 路共阴 PWM 恒流源驱动 | RGB 列驱动、灰度 PWM、帧缓存、开路检测 | 已取得 V1.3 数据手册和 V4.2 编程指南 |
| RT5990 | 锐发科技 | 16 路 NMOS 行管控制 | 公共阴极行选择、串行译码、鬼影/串亮抑制 | 官网只有产品摘要，未公开可下载完整手册 |

系统可简化为：

```text
接收卡/板上控制器
   |-- SIN + DCLK + LE + ROW --> ICND2069AP 链
   |                              |
   |                              +-- 16 路恒流源 --> RGB LED 阳极
   |
   +-- 行选择串行信号 ----------> RT5990 链
                                  |
                                  +-- 16 路 NMOS --> LED 公共阴极 --> GND
```

图中 RT5990 的信号名和它与 ICND2069 `ROW` 的具体连接方式尚未确认，不能据此直接接线。

## ICND2069AP

### 主要规格

| 项目 | 官方 V1.3 资料 |
|---|---|
| 架构 | 16 通道 PWM 恒流源驱动，共阴 LED 应用 |
| 扫描数 | 1～64 扫 |
| 帧缓存 | 官网标称“32 KB SRAM”；V1.3 PDF 只确认存在 SRAM，未在正文中标明容量单位 |
| 正常供电范围 | 2.6～5.0 V |
| 正常恒流范围 | VDD=5 V 或 3.8 V：0.5～18 mA/通道；VDD=2.8 V：0.5～15 mA/通道 |
| 绝对最大输出电流 | 25 mA/通道，不是推荐工作电流 |
| 最大 DCLK | 35 MHz |
| 编程指南建议 DCLK | 默认 12.5 MHz，通常使用 4～16 MHz |
| 电流精度 | 通道间和芯片间均小于 ±2%（最大值） |
| 电流增益 | 8 bit，约 22%～200% |
| 工作温度 | -40～85 ℃ |
| 输出开路检测 | 支持 |
| 封装 | AP：SSOP24；AN-01：QFN24 |

以上来自集创官网产品页、V1.3 数据手册和 V4.2 编程指南。[cite:1][cite:2][cite:3]

第三方 Olympian 汇总页给出 `0.5～25 mA`，但这把数据手册中的 25 mA 绝对最大额定值混入了工作范围。设计和试机应以官方 V1.3 的 18 mA 上限为准，更不能一开始就按上限运行。[cite:2][cite:8]

SRAM 容量也存在资料边界：当前官网和第三方汇总页写 `32 KB`，已取得的 V1.3 PDF 只在框图中标出 SRAM，并未给出容量。考虑到 LED 驱动资料也常用 Kbit，不能仅凭网页把 bit/byte 单位继续用于内存布局推导。[cite:1][cite:2][cite:8]

### ICND2069AP 引脚

SSOP24 顶视图的引脚定义如下：[cite:2][cite:3]

| 引脚 | 名称 | 功能 |
|---:|---|---|
| 1 | GND | 电源地 |
| 2 | SIN | 串行数据输入 |
| 3 | DCLK | 数据移位及命令时钟 |
| 4 | LE | 数据锁存和命令输入 |
| 5～20 | OUT0～OUT15 | 16 路恒流源输出 |
| 21 | ROW | 换行同步信号 |
| 22 | SDO | 串行数据输出，用于级联或回读 |
| 23 | REXT | 外接到 GND 的恒流设定电阻 |
| 24 | VDD | 芯片电源 |

方便探针定位的两侧排列：

```text
              ICND2069AP，顶视图
         +-------------------------+
 GND   1 |                         | 24 VDD
 SIN   2 |                         | 23 REXT
 DCLK  3 |                         | 22 SDO
 LE    4 |                         | 21 ROW
 OUT0  5 |                         | 20 OUT15
 OUT1  6 |                         | 19 OUT14
 OUT2  7 |                         | 18 OUT13
 OUT3  8 |                         | 17 OUT12
 OUT4  9 |                         | 16 OUT11
 OUT5 10 |                         | 15 OUT10
 OUT6 11 |                         | 14 OUT9
 OUT7 12 |                         | 13 OUT8
         +-------------------------+
```

### 电气注意事项

- 绝对最大 VDD 是 6.0 V，正常工作上限是 5.0 V；二者不能混用。
- 数据手册在 VDD 约 5 V 条件下给出的输入门限为：高电平至少 `0.7 × VDD`，低电平至多 `0.3 × VDD`。如果芯片实际由 5 V 供电，3.3 V GPIO 低于 3.5 V 的保证高电平门限，不能默认可靠，应先测 VDD 和板上的电平转换器。
- `OUT0～OUT15` 是恒流输出，不是普通逻辑脚；绝对最大输出电压为 10 V。
- `DCLK` 内部有下拉；不要依赖悬空输入。
- 上电前先确认 `REXT` 阻值。数据手册给出的关系为 `Iout = 12 × Gain / REXT`；当 Gain=100%、REXT 以 kΩ计时，结果为 mA。例如 1.24 kΩ 对应约 9.7 mA。实际电流还受配置寄存器增益影响。[cite:2]

### 数据和命令接口

ICND2069 把灰度数据、配置地址和配置值都通过同一个 16 bit 移位寄存器输入。命令由 `LE=1` 期间出现的 DCLK 上升沿个数编码：[cite:3]

| LE 高电平内 DCLK 上升沿数 | 命令 | 功能 |
|---:|---|---|
| 1 | DATA_LATCH | 把 16 bit 灰度数据送入 SRAM |
| 3 | VSYNC | 帧同步 |
| 5 | WR_CFG | 写配置寄存器 |
| 7 | RD_CFG | 读配置寄存器 |
| 9 | SOFT_RST | 复位寄存器以外的功能 |
| 11 | EN_OP | 打开全部恒流输出 |
| 12 | DIS_OP | 关闭全部恒流输出 |
| 14 | PRE_ACT | 临时解除配置写保护 |

关键行为：

1. 每个像素灰度值为 16 bit。
2. 一个芯片每行按 `OUT15` 到 `OUT0` 的顺序接收 16 个灰度值，然后进入下一扫描行。
3. 上电后恒流输出默认关闭；收到第一帧后仍需发送 `EN_OP`。
4. 写寄存器前要发送 `PRE_ACT`，再写 `0x00=0xAA`、`0x01=0xAA` 解锁；结束时写 `0x00=0x55`、`0x01=0x55`。
5. `ROW` 上升沿开始显示新行。第一组第一行使用 12 个 DCLK 宽度的高脉冲，其余换行使用 4 个 DCLK 宽度；行管选择必须与它同步。
6. 编程指南的默认寄存器表不是任意板子的可直接复制配置。扫描数、组数、每行时长、RGB 电流增益、消隐和鬼影补偿都与具体 PCB 和灯珠相关。

### 刷新率并不等于视频帧率

官网标称刷新率为 3840 Hz；官方应用案例还提到 45 扫下可达到 3840 Hz 以上和 14 bit 灰阶。[cite:1][cite:4] 这里是 LED PWM 扫描刷新率，不是 HDMI/视频输入的 3840 fps。实际刷新率由 DCLK、内部分频、扫描数、组数、每行 PWM 时间和灰阶位宽共同决定。

## RT5990

### 官方能够确认的信息

锐发官网把 RT5990 分类为“行管控制芯片”，公开摘要只有以下四项：[cite:5]

- 16 路 NMOS；
- 超低静态电流损耗；
- 消除鬼影与 LED 坏点引起的串亮；
- 串行译码，简化 PCB 线路布局。

这些信息足以确认它不是 RGB 恒流驱动，也不是普通电源芯片，而是共阴扫描行的集成 NMOS 开关和译码器。

### 仍无法确认的信息

截至本次检索，锐发官网的 RT5990 下载栏为空，未找到可信的完整数据手册。因此下列项目不能凭同厂其他型号代填：

- 封装型号和准确引脚定义；
- VDD 范围和逻辑输入门限；
- 每通道最大持续/脉冲电流、导通电阻和热阻；
- 串行数据、时钟、锁存、消隐等引脚名称与时序；
- 16 路输出是单颗覆盖 16 扫，还是支持多颗级联到 32/64 扫；
- 鬼影消除、预充电和坏灯抑制的具体配置方法；
- 上电默认输出状态。

在没有 RT5990 手册或原接收卡波形之前，不应照抄 RT5929/RT5988 的引脚接线。

### 同厂相邻型号提供的有限参考

锐发的 RT5929 是 8 路共阴 NMOS 行管，包含 `DIN/LCK/BK/DOUT` 串行控制、预充电、坏灯抑制，并明确可替代 3-8 译码器；RT5966 共阴恒流驱动手册则展示了恒流芯片与 RT5988 行管配合扫描的结构。[cite:6][cite:7]

这支持对 RT5990“串行移位/锁存后选通一条公共阴极行”的架构判断，但只能作为同系列工作原理参考，不能证明 RT5990 使用相同引脚、位序或电气参数。

## 对这块 P0.93 板的判断

### 可以确定

- 板子采用共阴架构。
- 实物接口带有 `Vrg`、`Vb` 两组电源标识。
- ICND2069AP 每颗提供 16 路 RGB 恒流列输出。
- RT5990 每颗提供 16 路 NMOS 行输出。
- 驱动协议带帧缓存和配置寄存器，不属于可用普通 GPIO 慢速逐像素刷新的简单面板。
- NovaStar 的多种接收卡固件和 COEX 控制器公开列出 ICND2069 支持，但实际固件还必须匹配行管芯片和模组配置。[cite:8]

### 仅凭芯片型号不能确定

- 模组分辨率、扫描数和 RGB 数据组数；
- ICND2069AP 与 RT5990 的数量及级联分区；
- 接口座定义是否为 HUB75、私有排线或板对板高速接口；
- RGB 排列、行列映射、蛇形方向和级联顺序；
- `Vrg`、`Vb` 分别连接哪些颜色以及各自的额定电压；
- 其他电源轨、电流上限和上电时序；
- 原接收卡配置中的电流、Gamma、换行时间和补偿参数。

`P0.93` 只说明像素间距约 0.93 mm，不说明上述电气拓扑。

## 到货后的安全检查顺序

1. 先拍清楚正反面全图、接口、芯片数量、丝印、模组宽高像素和任何接收卡型号。
2. 不上电，用万用表确认电源座正负极、VDD 到地阻值、保险丝和 DC/DC 输出网络。
3. 测量每颗 ICND2069AP 的 23 脚 `REXT` 到地阻值，并记录 RGB 三组是否使用不同阻值。
4. 使用限流电源上电，先设较低电流限额；确认板上 5 V、3.8 V、3.3 V 等实际电源轨，不能只按接口外观猜。
5. 若原配接收卡能点亮，先保存其配置文件、固件版本和驱动芯片选择，再抓波形。
6. 示波器优先探测 ICND2069AP 的 `SIN(2)`、`DCLK(3)`、`LE(4)`、`ROW(21)`、`SDO(22)`；先测电压范围，再接逻辑分析仪。
7. 同步寻找 RT5990 周围连接到接口的小信号脚和连接到 LED 公共阴极的粗铜输出脚，通过通断和波形反推引脚。
8. 先复现黑屏和单行低亮测试，再尝试全屏图案。不要从全白、最大增益或长时间固定行选通开始。

## 建议保留的原始资料

- 原卖家提供的接收卡、转接板、电源和排线；
- 能点亮时的接线照片与视频；
- 接收卡配置文件，例如 NovaStar `.rcfgx`/`.ncp`；
- 控制软件版本、接收卡固件版本和芯片选择截图；
- 板子背面所有电阻网络和测试点的高清照片。

对这种带 SRAM 的 PWM 驱动板，原配置文件的价值通常高于单独一张芯片引脚图。
